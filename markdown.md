# My Dream Coding Project: EcoTrack
- - -
## Project Overview
- - -
**EcoTrack** is an app designed to help users track their daily carbon *footprint* and make small, sustaniable choices that add up to a big impact.
Its built using **HTML**, **CSS** and **JavaScript**- but one day, i want to expand it into a full web platform!
